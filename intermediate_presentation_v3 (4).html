Motivation

Two forces, one strategic gap

🏛️
Regulatory driver
FIDA / Open Finance
EU consent-based data sharing: delayed, weakened, outcome uncertain.
🤖
Market driver
Rise of AI agents & MCP (Model Context Protocol)
Agents create a de-facto need for standardized financial-data interfaces, regardless of FIDA.
Lead
Set standards early, win the first ecosystem partnerships, shape the agent interface.
Do the minimum
Comply and protect: expose the least data and sacrifice external optionality.
Close off
Resist opening and optimize internally, at the risk of losing the customer interface.
"The development towards an open data economy will continue regardless of whether FIDA is adopted or delayed."Mounaim Cortet, Innopay (Oliver Wyman) · Deutsche Bank Data Studio, 2026

The gap: DB has an external API program, but how to position it for an AI-agent data economy, and which business models it unlocks, is still open. Doing nothing cedes the customer to uncontrolled screen-scraping.

Research Question

What we set out to answer

Main research question
How can Deutsche Bank leverage its API program to build sustainable business models in an AI-agent-driven data economy, with or without FIDA?
RQ1 · Interfaces
What role do AI-agent interfaces (APIs & MCP) play in governed financial-data access?
RQ2 · Value
Which data & services create defensible value once open data is commoditized?
RQ3 · Positioning
Should DB lead, do the minimum, or close off, and how do AI agents shift that calculus?

First Results

Findings so far & related work

Preliminary findings
DB is already beyond PSD2
Premium APIs for German SMEs without a BaFin licence; wealth-management & SME interfaces live. The open question is strategic, not technical.
Revenue is mostly indirect
Check24 → more account openings; investment-ordering APIs → direct revenue; distribution partners speed acquisition. Direct API prices are minimal.
Data distribution is the bottleneck
Mainframe batch vs. real-time online-banking data; only partial unified data model; a central data layer is still being built.
Related work & sources
Open Finance literature & whitepapers
Industry Open Finance whitepapers (Overview, AI, FinTech, Infrastructure, Insurance, Strategy); academic Open Banking research on APIs & data ecosystems.
Market evidence of agent interfaces
Plaid × Perplexity/OpenAI; LSEG × OpenAI; PayPal agentic commerce — third parties are already becoming the financial interface.
Competitor scan (in progress)
EU front-runners — Dutch banks, Revolut — benchmarked on API offering, strategy & realized use cases.
